# Security Policy

## Supported versions

This repository is a service, not a versioned package, so it has no releases. Only the `master` branch receives security fixes. Vercel deploys it to `github-profile-trophy.nixrajput.com`, and the composite action in `action.yml` runs from it.

| Version                 | Supported |
| ----------------------- | --------- |
| `master` (deployed)     | Yes       |
| Older commits and forks | No        |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

### Option 1 - GitHub private advisory (preferred)

Use GitHub's private vulnerability reporting:

[https://github.com/nixrajput/github-profile-trophy/security/advisories/new](https://github.com/nixrajput/github-profile-trophy/security/advisories/new)

### Option 2 - Email

Send a description of the vulnerability to **<nkr.nikhil.nkr@gmail.com>**. Include:

- A clear description of the issue and its potential impact.
- Steps to reproduce or a proof-of-concept.
- Any suggested remediation if you have one.

## Response expectations

| Milestone          | Target                           |
| ------------------ | -------------------------------- |
| Acknowledgement    | Within 72 hours                  |
| Initial assessment | Within 7 days                    |
| Fix or mitigation  | Within 30 days for high-severity |

You will be credited in the fix's pull request unless you prefer to remain anonymous. Thank you for helping keep this project secure.
